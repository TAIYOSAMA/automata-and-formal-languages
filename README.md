# automata-and-formal-languages
Reports for Automata and Formal Languages at Tohoku Univ.

## Usage
To use this repository, you should install `Nix` and `direnv`.
I recommend you to install Nix by `nix-installer` because it can automatically enables the function of `flakes`. Also, `direnv` should be managed by `Home Manager` which is a Nix Library to manage your environment.

## Caution
This repository expects to use `latexmk` as the LaTex compiler.
